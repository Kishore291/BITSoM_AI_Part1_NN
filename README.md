# Customer Churn Prediction (Neural Networks)

## Overview
This repository contains Part 1 of the AI Solution Design project. The objective is to build a Deep Learning model to predict customer churn using tabular data. 

## Technical Stack
* **Data Processing:** Pandas, NumPy
* **Machine Learning / Preprocessing:** Scikit-Learn (StandardScaler, One-Hot Encoding)
* **Deep Learning:** TensorFlow / Keras (Sequential API)

## Repository Structure
* `notebook.ipynb`: The complete code for data exploration, preprocessing, and model training.
* `requirements.txt`: The required Python libraries to run the environment.
* `results/`: Contains the final model evaluation metrics and sample predictions.
